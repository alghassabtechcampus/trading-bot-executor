# breakout_btc — الاختراق + الحَكَم (البيتكوين اليومي)

استراتيجية ثانية بجانب liq_flush، من دورة أسهم بدر. **spot فقط، شراء فقط.**
الحَكَم يقرّر متى يُسمح لها بالدخول: البيتكوين لازم يكون صاعد على اليومي.

التوقّع من الباك-تيست (10 عملات، 4 ساعات، 2023-01 → 2026-10، رسوم 0.15% لكل جهة):
**~11 صفقة شهرياً على 10 عملات، 39% رابحة، +1.56% متوسط الصفقة، عامل ربح 1.68**.
الصفقة الرابحة كبيرة والخاسرة صغيرة، فسلسلة 5–6 خسائر متتالية طبيعية.
أي شيء مختلف جوهرياً بعد 20 صفقة = توقّف وراجع.

---

## 1. القواعد (مثبّتة في bo_signal.py)

| | القاعدة |
|---|---|
| القمة/القاع | شمعة أعلى/أدنى من شمعتين يمين وشمعتين يسار |
| الحَكَم | BTC يومي: آخر قاعين صاعدين + الإغلاق فوق آخر قاع |
| الدخول | إغلاق 4 ساعات فوق آخر قمة (والسابقة تحتها) + فوليوم > 1.5× متوسط 20 + شمعة صاعدة تغلق في نصفها العلوي |
| الوقف | آخر قاع مؤكد، ويُرفع مع كل قاع أعلى جديد |
| الخروج | **إغلاق** 4 ساعات تحت الوقف (الذيل وحده لا يُخرج) |
| الحدود | صفقة لكل عملة، نفس القمة لا تُدخل مرتين، عمر الإشارة ≤ ساعتين |
| العملات | BTC ETH BNB XRP ADA LTC SOL DOGE AVAX |

`tests/test_bo_signal.py` يعيد تشغيل الباك-تيست الأصلي (منقول من JavaScript سطراً
بسطر) ويقارنه شمعة بشمعة بالمسار الحي (`evaluate` + `trail_and_check`):
نفس الصفقات بالضبط على 10 سلاسل مصطنعة. أي نظر للمستقبل يكسر الاختبار.

## 2. متغيّرات البيئة

```bash
BO_ENABLED=false        # المفتاح القاتل. false يمنع الدخول ويكمل الخروج
BO_DRY_RUN=false        # true = كل شيء بدون أوامر، تحت bo:dry:*
BO_USDT_PER_TRADE=10
```

## 3. n8n — سير عمل واحد جديد

- **Schedule Trigger:** Cron `3 * * * *` (كل ساعة، الدقيقة 3 — بعد liq_tick بدقيقة)
- **HTTP Request:** `POST https://<executor>/bo_tick`، Header
  `X-Webhook-Signature = <TRADING_WEBHOOK_SECRET>`، Body `{}`، Timeout `120000`،
  Retry On Fail: 3 مرات كل 5000ms (القفل `bo:tick:lock` يمنع الدخول المكرّر)
- **Split Out** على `messages` ← **Telegram**
- **Split Out** على `journal` ← **Google Sheet** (تبويب جديد `breakout`)، أعمدة:
  `strategy event symbol entry_time entry_price qty exit_time exit_price exit_reason
  stop_level initial_stop fees pnl pnl_pct hold_hours signal_bar pivot_high vol_ratio dry_run`
- نفس سير "تنبيه فشل" كـ errorWorkflow.

## 4. التشغيل

1. انشر الفرع، واترك `BO_ENABLED=true BO_DRY_RUN=true` أسبوعاً.
   تحقّق: `status=ok`، `regime` يظهر، `scan.errors=0`.
2. بعدها `BO_DRY_RUN=false` بـ 10 USDT.

مراقبة: `GET /bo_positions` (المراكز + الوقف الحالي + الحَكَم)، `GET /regime`،
`GET /bo_health`.

## 5. فروق مقصودة عن الباك-تيست

| | الباك-تيست | الحي |
|---|---|---|
| سعر الدخول | إغلاق شمعة الإشارة | سعر السوق بعد الإغلاق بدقائق (حتى ساعتين عند اللحاق) |
| سعر الخروج | إغلاق الشمعة تحت الوقف | سعر السوق في النبضة التالية لإغلاقها |
| العملات | 10 مع LINK | 9 (LINK لا يُباع عبر الـ API) |

## 6. التقاطع مع liq_flush

مفاتيح منفصلة (`bo:*` مقابل `liq:*`)، أوامر `bo_` مقابل `liq_`. breakout يرفض
الدخول على عملة فيها `liq:open:*` أو `trade:*`/`pending:*`. الاتجاه المعاكس غير
ممنوع (liq يقدر يدخل عملة يحملها breakout) — البيع في الاثنين مسقوف بالكمية
المسجّلة والرصيد، والاحتمال ضعيف (liq يدخل عند الانهيارات، breakout عند الاختراقات
في سوق صاعد).
